LOCAL PREVIEW
Open index.html in Chrome, Edge, Firefox or Safari. Nothing is published.

EDIT YOUR DETAILS
Edit index.html to add your email and GitHub links and to adjust the biographical and publication entries.
Replace assets/img/profile.svg with your own photo (update its path in index.html if using .jpg or .png).

PUBLISH LATER
Upload index.html and the assets folder to a GitHub Pages repository.
